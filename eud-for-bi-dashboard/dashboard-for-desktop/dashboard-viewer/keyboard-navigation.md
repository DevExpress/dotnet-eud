# Keyboard Navigation

The WinForms Dashboard Viewer supports keyboard navigation between dashboard items. Navigation within item content depends on the underlying WinForms control for each item type.

## Keyboard Shortcuts

| Action | Keys |
| --- | --- |
| Move focus between dashboard items. | <kbd>F5</kbd> / <kbd>F6</kbd> |
| Apply a card as a Master Filter. | <kbd>Enter</kbd> / <kbd>Space</kbd> |
| Toggle a predefined interval in a Date Filter item. | <kbd>Enter</kbd> |
| Navigate between cards in a Card item. | Arrow keys |

## Ribbon and Toolbar Navigation

The Ribbon, toolbars, and menus support keyboard navigation — you can move between bars and invoke actions using the keyboard.

## Dialogs

The following dialogs support standard keyboard interaction:

- Data Inspector
- Print/Export (PDF, Excel, Image)
- Set Predefined Intervals (Range Filter)
- Dashboard Parameters

## Limitations

The following keyboard navigation limitations apply to the WinForms Dashboard Viewer:

- You cannot navigate between buttons in the dashboard title and dashboard item captions.
- You cannot open a dashboard item context menu from the keyboard.
- Keyboard navigation inside item content is not supported for the following dashboard items: Chart, Pie, Scatter Chart, Gauge, and Treemap.
