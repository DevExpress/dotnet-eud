# Keyboard Shortcuts

The following keyboard shortcuts work in the Document Viewer and Web Report Designer Preview. Toolbar and Tab Panel tooltips also display shortcuts.

## Shortcuts

| Action | Key (Windows) | Key (macOS) |
|---|---|---|
| Print the report | <kbd>Ctrl</kbd> + <kbd>P</kbd> | <kbd>Cmd</kbd> + <kbd>P</kbd> |
| Set **Whole Page** zooming | <kbd>Ctrl</kbd> + <kbd>0</kbd> | <kbd>Cmd</kbd> + <kbd>0</kbd> |
| Zoom in the report | <kbd>Ctrl</kbd> + <kbd>Plus</kbd> | <kbd>Cmd</kbd> + <kbd>Plus</kbd> |
| Zoom out the report | <kbd>Ctrl</kbd> + <kbd>Minus</kbd> | <kbd>Cmd</kbd> + <kbd>Minus</kbd> |
| Toggle multi-page mode | <kbd>Alt</kbd> + <kbd>M</kbd> | <kbd>Option</kbd> + <kbd>M</kbd> |
| Highlight editing fields | <kbd>Alt</kbd> + <kbd>H</kbd> | <kbd>Option</kbd> + <kbd>H</kbd> |
| Go to the next page | <kbd>Right Arrow</kbd> | <kbd>Right Arrow</kbd> |
| Go to the previous page | <kbd>Left Arrow</kbd> | <kbd>Left Arrow</kbd> |
| Go to the last page | <kbd>Ctrl</kbd> + <kbd>Right Arrow</kbd> | <kbd>Cmd</kbd> + <kbd>Right Arrow</kbd> |
| Go to the first page | <kbd>Ctrl</kbd> + <kbd>Left Arrow</kbd> | <kbd>Cmd</kbd> + <kbd>Left Arrow</kbd> |
| Copy the selected content to the Clipboard | <kbd>Ctrl</kbd> + <kbd>C</kbd> | <kbd>Cmd</kbd> + <kbd>C</kbd> |
| Open the Search Panel | <kbd>Ctrl</kbd> + <kbd>F</kbd> | <kbd>Cmd</kbd> + <kbd>F</kbd> |
| Open the Parameters Panel | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Y</kbd> | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>Y</kbd> |
| Open the Document Map | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>M</kbd> | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>M</kbd> |
| Open Export Options | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd> | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd> |
| Open Keyboard Shortcuts | <kbd>Question Mark(?)</kbd> | <kbd>Question Mark(?)</kbd> |
