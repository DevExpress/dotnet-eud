# Keyboard Shortcuts

## Shortcuts

| Action | Key (Windows) | Key (macOS) |
|---|---|---|
| Print the report | <kbd>Ctrl</kbd> + <kbd>P</kbd> | <kbd>⌘</kbd> + <kbd>P</kbd> |
| Set **Whole Page** zooming | <kbd>Ctrl</kbd> + <kbd>0</kbd> | <kbd>⌘</kbd> + <kbd>0</kbd> |
| Zoom in the report | <kbd>Ctrl</kbd> + <kbd>+</kbd> | <kbd>⌘</kbd> + <kbd>+</kbd> |
| Zoom out the report | <kbd>Ctrl</kbd> + <kbd>-</kbd> | <kbd>⌘</kbd> + <kbd>-</kbd> |
| Toggle multi-page mode | <kbd>Alt</kbd> + <kbd>M</kbd> | <kbd>⌥</kbd> + <kbd>M</kbd> |
| Highlight editing fields | <kbd>Alt</kbd> + <kbd>H</kbd> | <kbd>⌥</kbd> + <kbd>H</kbd> |
| Open search | <kbd>Ctrl</kbd> + <kbd>F</kbd> | <kbd>⌘</kbd> + <kbd>F</kbd> |
| Switch to the next page | <kbd>Right Arrow</kbd> | <kbd>Right Arrow</kbd> |
| Switch to the previous page | <kbd>Left Arrow</kbd> | <kbd>Left Arrow</kbd> |
| Switch to the last page | <kbd>Ctrl</kbd> + <kbd>Right Arrow</kbd> | <kbd>⌘</kbd> + <kbd>Right Arrow</kbd> |
| Switch to the first page | <kbd>Ctrl</kbd> + <kbd>Left Arrow</kbd> | <kbd>⌘</kbd> + <kbd>Left Arrow</kbd> |
| Copy the selected content to the Clipboard | <kbd>Ctrl</kbd> + <kbd>C</kbd> | <kbd>⌘</kbd> + <kbd>C</kbd> |

## Keyboard Navigation in Accessibility Mode

### Toolbar

| Action | Shortcut Key |
|---|---|
| Move focus from the browser to the Document Viewer Toolbar | <kbd>Tab</kbd> |
| Move focus to the next item in toolbar | <kbd>Right Arrow</kbd> |
| Move focus to the previous item in toolbar | <kbd>Left Arrow</kbd> |
| Activate the selected toolbar editor | <kbd>Enter</kbd> or <kbd>Space</kbd> |
| Open and display a drop-down list or menu | <kbd>Alt</kbd> + <kbd>Down Arrow</kbd> |
| Move between editor values in the activated Pager or Zoom combo box | <kbd>Up Arrow</kbd>, <kbd>Down Arrow</kbd> |
| Deactivate the combo box | <kbd>Esc</kbd> |

> [!NOTE]
> When you select the **Search** button, the Search Tab opens and receives focus.

### Document Page

| Action | Shortcut Key |
|---|---|
| Move focus to the Document Area (or to Drill-Through breadcrumbs if displayed) | <kbd>Tab</kbd> |
| Enter Document Read mode | <kbd>Enter</kbd> or <kbd>Space</kbd> |
| Move between bricks on a page | <kbd>Right Arrow</kbd>, <kbd>Left Arrow</kbd> |
| Exit Document Read mode | <kbd>Tab</kbd>, <kbd>Shift</kbd> + <kbd>Tab</kbd> |

### Tab Panel

| Action | Shortcut Key |
|---|---|
| Move focus to the Tab Panel | <kbd>Tab</kbd> |
| Move between tabs in the Tab Panel | <kbd>Up Arrow</kbd>, <kbd>Down Arrow</kbd> |
| Open or close the selected tab | <kbd>Enter</kbd> or <kbd>Space</kbd> |

### Preview Parameters Tab

| Action | Shortcut Key |
|---|---|
| Move to the next control inside the tab | <kbd>Tab</kbd> |
| Move to the previous control inside the tab | <kbd>Shift</kbd> + <kbd>Tab</kbd> |
| Activate the parameter editor | <kbd>Enter</kbd> or <kbd>Space</kbd> |
| Move to the browser toolbar from the last editor | <kbd>Tab</kbd> |
| Move to the Tab Panel from the first editor | <kbd>Shift</kbd> + <kbd>Tab</kbd> |

### Export Options Tab

| Action | Shortcut Key |
|---|---|
| Move to the next control inside the tab | <kbd>Tab</kbd> |
| Move to the previous control inside the tab | <kbd>Shift</kbd> + <kbd>Tab</kbd> |
| Move to the first control inside the tab | <kbd>Home</kbd> |
| Move to the last control inside the tab | <kbd>End</kbd> |
| Open the selected section | <kbd>Enter</kbd> or <kbd>Space</kbd> |
| Toggle the checkbox state | <kbd>Enter</kbd> or <kbd>Space</kbd> |
| Display a list of values in a combo box | <kbd>Alt</kbd> + <kbd>Down Arrow</kbd> |
| Deactivate the editor and move to the next editor | <kbd>Tab</kbd> |
| Move to the browser toolbar from the last editor | <kbd>Tab</kbd> |
| Move to the Tab Panel from the first editor | <kbd>Shift</kbd> + <kbd>Tab</kbd> |

### Search Tab

| Action | Shortcut Key |
|---|---|
| Move to the next control inside the tab | <kbd>Tab</kbd> |
| Move to the previous control inside the tab | <kbd>Shift</kbd> + <kbd>Tab</kbd> |
| Search a document for the specified text | <kbd>Enter</kbd> |
| Navigate to the next search result | <kbd>Down Arrow</kbd> |
| Navigate to the previous search result | <kbd>Up Arrow</kbd> |
| Highlight the matching text in the document | <kbd>Enter</kbd> |
| Exit the search result list | <kbd>Shift</kbd> + <kbd>Tab</kbd> |
| Move to the browser toolbar from the last editor | <kbd>Tab</kbd> |
| Move to the Tab Panel from the first editor | <kbd>Shift</kbd> + <kbd>Tab</kbd> |

> [!NOTE]
> When navigating search results, the Search Tab remains focused.

### Document Map Tab

| Action | Shortcut Key |
|---|---|
| Expand the document's bookmark tree | <kbd>Alt</kbd> + <kbd>Right Arrow</kbd> |
| Collapse the document's bookmark tree | <kbd>Alt</kbd> + <kbd>Left Arrow</kbd> |
| Open the document page that contains the bookmark and highlight the bookmark | <kbd>Enter</kbd> |
| Move to the browser toolbar from the last editor | <kbd>Tab</kbd> |
| Exit the Document Map Tab and move to the Tab Panel | <kbd>Shift</kbd> + <kbd>Tab</kbd> |

> [!NOTE]
> When navigating bookmarks, the Document Map Tab remains focused.
