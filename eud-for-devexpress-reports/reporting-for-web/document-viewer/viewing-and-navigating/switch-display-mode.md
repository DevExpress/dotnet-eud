# Switch Between Single Page and Multipage View

You can switch between the Single Page and Multipage modes with the **Toggle Multipage Mode** button located in the Document Viewer toolbar.

![Web Document Viewer - Toggle Multipage Button in Toolbar](../../images/img24556.png)

In the default Single Page mode, the Document Viewer displays only one page. You can navigate between document pages with the navigation buttons and drop-down list (see [Navigate Between Pages](navigate-between-pages.md)).

![Web Document Viewer - Single Page Mode](../../images/img121843.png)

In the Multipage mode, the Document Viewer displays several document pages. In addition to the standard navigation features, a vertical scroll bar lets you scroll through pages.

![Web Document Viewer - Multipage Mode](../../images/img121844.png)
