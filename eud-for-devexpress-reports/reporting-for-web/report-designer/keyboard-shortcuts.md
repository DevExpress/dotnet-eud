# Keyboard Shortcuts

The following table lists default keyboard shortcuts and corresponding actions in the Web Report Designer.

## File Operations

| Action | Key (Windows) | Key (macOS) |
|---|---|---|
| Create a new report | <kbd>Alt</kbd> + <kbd>N</kbd> | <kbd>⌥</kbd> + <kbd>N</kbd> |
| Open the report | <kbd>Ctrl</kbd> + <kbd>O</kbd> | <kbd>⌘</kbd> + <kbd>O</kbd> |
| Save the report | <kbd>Ctrl</kbd> + <kbd>S</kbd> | <kbd>⌘</kbd> + <kbd>S</kbd> |
| Print the report | <kbd>Ctrl</kbd> + <kbd>P</kbd> | <kbd>⌘</kbd> + <kbd>P</kbd> |

## Clipboard Operations

| Action | Key (Windows) | Key (macOS) |
|---|---|---|
| Cut the selected content to the Clipboard | <kbd>Ctrl</kbd> + <kbd>X</kbd> | <kbd>⌘</kbd> + <kbd>X</kbd> |
| Copy the selected content to the Clipboard | <kbd>Ctrl</kbd> + <kbd>C</kbd> | <kbd>⌘</kbd> + <kbd>C</kbd> |
| Paste the content from the Clipboard | <kbd>Ctrl</kbd> + <kbd>V</kbd> | <kbd>⌘</kbd> + <kbd>V</kbd> |

## Zoom in and out the Report

| Action | Key (Windows) | Key (macOS) |
|---|---|---|
| Set the 100% zoom factor | <kbd>Ctrl</kbd> + <kbd>0</kbd> | <kbd>⌘</kbd> + <kbd>0</kbd> |
| Zoom in the report | <kbd>Ctrl</kbd> + <kbd>+</kbd> | <kbd>⌘</kbd> + <kbd>+</kbd> |
| Zoom out the report | <kbd>Ctrl</kbd> + <kbd>-</kbd> | <kbd>⌘</kbd> + <kbd>-</kbd> |

## Undo and Redo Operations

| Action | Key (Windows) | Key (macOS) |
|---|---|---|
| Undo the previous action | <kbd>Ctrl</kbd> + <kbd>Z</kbd> | <kbd>⌘</kbd> + <kbd>Z</kbd> |
| Redo the previous action | <kbd>Ctrl</kbd> + <kbd>Y</kbd> | <kbd>⌘</kbd> + <kbd>Y</kbd> |

## Data Source Wizard Operations

| Action | Key (Windows) | Key (macOS) |
|---|---|---|
| Open the **Data Source Wizard** | <kbd>Alt</kbd> + <kbd>W</kbd> | <kbd>⌥</kbd> + <kbd>W</kbd> |
| Open the preview of the selected statement in the **Query Builder** | <kbd>Ctrl</kbd> + <kbd>E</kbd> | <kbd>⌘</kbd> + <kbd>E</kbd> |

## Script Editor Operations

| Action | Key (Windows) | Key (macOS) |
|---|---|---|
| Open the **Script Editor** | <kbd>Alt</kbd> + <kbd>R</kbd> | <kbd>⌥</kbd> + <kbd>R</kbd> |
| Validate the script | <kbd>Alt</kbd> + <kbd>L</kbd> | <kbd>⌥</kbd> + <kbd>L</kbd> |

## Preview Operations

For keyboard shortcuts available in the preview mode, refer to [Document Viewer — Keyboard Shortcuts](../document-viewer/viewing-and-navigating/keyboard-shortcuts.md).
