# WinForms End-User Report Designer Keyboard Shortcuts

## Operations with Report Controls

### Copy/Paste a Report Control

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>C</kbd> | Copy the selected control. |
| <kbd>Ctrl</kbd> + <kbd>V</kbd> | Paste the copied control. |

![Copy and paste a report control using Ctrl+C and Ctrl+V](../../../../images/winforms-eurd-shortcuts/ctrl_c_or_v.gif)

### Cut a Report Control

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>X</kbd> | Cut the selected control. |

![Cut a report control using Ctrl+X](../../../../images/winforms-eurd-shortcuts/ctrl_x.gif)

### Delete a Report Control

| Key | Action |
|---|---|
| <kbd>Delete</kbd> | Remove the selected control. |

![Delete a report control using the Delete key](../../../../images/winforms-eurd-shortcuts/delete.gif)

### Undo / Redo an Action

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> | Undo the last operation. |
| <kbd>Ctrl</kbd> + <kbd>Y</kbd> | Repeat the last undone operation. |

![Undo and redo actions using Ctrl+Z and Ctrl+Y](../../../../images/winforms-eurd-shortcuts/undo.gif)

### Slide a Report Control to the End of the Area with a Minimum Indent

Use arrow keys to slide a control to the end of the area with a minimum indent:

| Key | Action |
|---|---|
| <kbd>Up Arrow</kbd> | Slide a control up. |
| <kbd>Down Arrow</kbd> | Slide a control down. |
| <kbd>Left Arrow</kbd> | Slide a control left. |
| <kbd>Right Arrow</kbd> | Slide a control right. |

![Slide a report control to the end of the area using arrow keys](../../../../images/winforms-eurd-shortcuts/arrow.gif)

### Shift a Report Control Pixel by Pixel

Use Ctrl + arrows to shift a control pixel by pixel:

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>Up Arrow</kbd> | Shift a control one pixel upward. |
| <kbd>Ctrl</kbd> + <kbd>Down Arrow</kbd> | Shift a control one pixel down. |
| <kbd>Ctrl</kbd> + <kbd>Left Arrow</kbd> | Shift a control one pixel to the left. |
| <kbd>Ctrl</kbd> + <kbd>Right Arrow</kbd> | Shift a control one pixel to the right. |

![Shift a report control pixel by pixel using Ctrl+arrow keys](../../../../images/winforms-eurd-shortcuts/ctrl_arrow.gif)

### Resize a Report Control to the Widest/Highest Possible Value

| Key | Action |
|---|---|
| <kbd>Shift</kbd> + <kbd>Up Arrow</kbd> | Move the control's bottom border to the lowest possible value. |
| <kbd>Shift</kbd> + <kbd>Down Arrow</kbd> | Move the control's bottom border to the highest possible value. |
| <kbd>Shift</kbd> + <kbd>Right Arrow</kbd> | Move the control's right border to the widest possible value. |
| <kbd>Shift</kbd> + <kbd>Left Arrow</kbd> | Move the control's right border to the narrowest possible value. |

![Resize a report control to the widest or highest possible value using Shift+arrow keys](../../../../images/winforms-eurd-shortcuts/shift_arrow.gif)

### Resize a Report Control Pixel by Pixel

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Up Arrow</kbd> | Move the control's bottom border upward by one pixel. |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Down Arrow</kbd> | Move the control's bottom border downward by one pixel. |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Left Arrow</kbd> | Move the control's right border to the left by one pixel. |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Right Arrow</kbd> | Move the control's right border to the right by one pixel. |

![Resize a report control pixel by pixel using Ctrl+Shift+arrow keys](../../../../images/winforms-eurd-shortcuts/ctrl_shift_arrow.gif)

### Resize a Report Control Proportionally

| Key | Action |
|---|---|
| <kbd>Shift</kbd> + <kbd>Drag</kbd> | Resize a control and preserve its aspect ratio. Initiate the operation in a corner anchor. |

![Resize a report control proportionally using Shift+Drag](../../../../images/winforms-eurd-shortcuts/Proportional-resize.gif)

### Clone a Report Control

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>Drag</kbd> | Clone a control. |

![Clone a report control using Ctrl+Drag](../../../../images/winforms-eurd-shortcuts/ctrl_move.gif)

### Select Multiple Report Controls

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>Click</kbd> or <kbd>Shift</kbd> + <kbd>Click</kbd> | Select/unselect multiple controls. |

![Select multiple report controls using Ctrl+Click or Shift+Click](../../../../images/winforms-eurd-shortcuts/ctrl_or_shift_click.gif)

### Rotate a Shape

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>Drag</kbd> | Rotate a shape. |

![Rotate a shape using Ctrl+Drag](../../../../images/winforms-eurd-shortcuts/ctrl_move_shape.gif)


## Operations with the Field List

| Key | Action |
|---|---|
| <kbd>Drag</kbd> a table | Add a table with bindings to all data fields. |

![Add a table with bindings to all data fields by dragging from the Field List](../../../../images/winforms-eurd-shortcuts/drag_drop.gif)

| Key | Action |
|---|---|
| <kbd>Shift</kbd> + <kbd>Drag</kbd> a table | Add a table with all data field names. |

![Add a table with all data field names using Shift+Drag from the Field List](../../../../images/winforms-eurd-shortcuts/shift_drag_drop.gif)

## Operations with the End-User Report Designer

| Key | Action |
|---|---|
| <kbd>F4</kbd> | Switch to the Designer tab. |
| <kbd>F5</kbd> | Switch to the Preview tab. |

![Switch between the Designer and Preview tabs using F4 and F5](../../../../images/winforms-eurd-shortcuts/f4_or_f5.gif)

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>L</kbd> | Save all opened report layouts. |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> | Save the selected report layout. |
| <kbd>Ctrl</kbd> + <kbd>O</kbd> | Open a `.repx` report. |
| <kbd>Ctrl</kbd> + <kbd>N</kbd> | Create a new report. |
| <kbd>Ctrl</kbd> + <kbd>W</kbd> | Create a new report with the Wizard. |
| <kbd>Ctrl</kbd> + <kbd>Scroll Down</kbd> | Zoom in the selected report. |
| <kbd>Ctrl</kbd> + <kbd>Scroll Up</kbd> | Zoom out the selected report. |
| <kbd>Ctrl</kbd> + <kbd>0</kbd> | Set zoom to 100%. |
